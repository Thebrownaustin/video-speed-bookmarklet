Safari Video Speed

Lift Moodle's 2x playback cap with a bookmarklet and hotkeys.

Speed

Drag this button to your Safari Favorites bar. Don't click it on this page.

Install

  1. In Safari, choose View → Show Favorites Bar.
  2. Drag the Speed button above onto the Favorites bar.
  3. Prefer to do it by hand? Bookmark any page, right-click the bookmark → Edit Address, and paste the code from the box below.

Use

  1. Open your lecture and click Speed once per page load.
  2. Enter a starting speed (for example 2.5). Choose whether to keep normal pitch.
  3. Then use the hotkeys:
  • ] faster by 0.25x
  • [ slower by 0.25x. At 0 the video pauses.
  • \ reset to 1x

Limitations

  • Can't reach videos in cross-origin iframes (Kaltura, Panopto, YouTube embeds). Open the video in its own tab and run it there.
  • Audio may crackle at high speeds. Choosing "Cancel" on the pitch prompt usually helps.
  • Run it again after a page reload.
  • Tested in Safari on macOS only.
